# 拾页 · 稍后读助手（1.10.0）

独立编写的 Chrome Manifest V3 扩展，支持通用网页离线收藏与 ChatGPT 对话导出。所有运行代码均在本目录，不加载原商业插件的脚本。ChatGPT 页内选择栏和导出弹窗延续原有样式；通用网站使用独立的页内面板。

## 安装或更新

1. 在 `chrome://extensions` 开启开发者模式，加载本目录 `exporter-extension`。
2. 已加载的用户点击本扩展的“重新加载”，然后刷新 ChatGPT 页面。
3. 在页面输入框附近点击 `SELECT`，勾选消息；从侧栏底部选择格式后点击“导出”。
4. PDF 会打开设置弹窗；确认后自动等待生成并下载。关闭页面后，可从扩展“导出设置”的最近任务恢复查询。
5. 服务默认是 `http://127.0.0.1:8765`。远程地址和访问令牌从“服务设置”修改。

建议先停用旧扩展，避免两套页面内按钮重叠。现有 `local-extension` 目录没有被修改。

## 通用网页快照

打开 HTTP(S) 网页，点击浏览器工具栏的拾页图标，再点击网页入口。首次使用按浏览器提示授权网页捕获、离屏处理与相应站点访问；权限按使用申请。网页右下角的“拾页”入口打开独立面板，可编辑标题、选择滚动加载图片，然后“保存到客户端”或“下载离线 HTML”。新采集模式需要客户端0.10.0并完成一次扩展ID配对；下载 HTML 不需要启动客户端。下载名称默认含时间戳。

每次保存会在同一条收藏中同时生成两个版本，无需提前选择：

- **原貌快照**：冻结捕获时的布局与媒体显示尺寸，保留多栏、背景、字体、伪元素与按钮中的图标。客户端按原始视口缩放，不再统一改写图片和列宽。
- **正文剪藏**：在本地提取正文，去除站点导航与侧栏，保留文章图片、标题、代码和表格，使用独立阅读排版。识别失败会保留原貌并显示原因。

保存到客户端后可切换“原貌快照 / 正文剪藏”，记住上次查看的版本与各自阅读位置。离线 HTML 显示原貌，并以内嵌的惰性 JSON 附带正文，导入客户端后也可切换。两个版本带入同网址已有的标注/笔记；正文中未保留的摘录可能无法定位。原貌快照无需外部 Chromium，使用安装插件的浏览器捕获；客户端继续使用系统 WKWebView。旧快照已丢失的样式需要重新采集，升级不会凭空恢复。

正文引擎取自用户提供的思源开源扩展，使用 Readability；没有接入思源内核或云端解析。第三方许可见 [ARTICLE-NOTICE.txt](vendor/ARTICLE-NOTICE.txt)。

弹窗可以为当前网站开启常驻页内入口，设置页可逐站关闭。关闭常驻入口不会撤销其他功能共用的资源权限，站点授权可在浏览器扩展管理中调整。不会在浏览器启动时自动收藏或唤醒客户端。

保存时过滤已识别的扩展悬浮界面，包括沉浸式翻译浮球/弹窗、部分语法/划词工具和扩展来源iframe；不会按fixed/sticky位置批量删除网页自身导航，也不删除翻译后的正文。原貌与正文版本共用过滤结果。过滤基于明确标记，未适配的扩展控件可能仍需补充规则；已保存的旧快照需重新收藏。此修复仅需更新扩展，客户端0.10.0可继续使用。

快照以浏览器 MHTML 捕获为基础，将样式、图片、字体、背景、可读取的 Canvas、开放 Shadow DOM 与已捕获的嵌入页面转换为单个离线 HTML；移除页面脚本、表单行为和网络加载。保存期间请保持来源标签页打开。捕获过程会恢复原滚动位置，不替换原页面 Canvas。

资源缺失或检测到滚动过程中内容被替换时，必须确认后才保存；可授权缺失资源所在域名并重试，也可取消。补取资源不携带登录凭据或来源信息，并有时间/大小限制。下载后的 HTML 与客户端快照均可离线阅读；普通来源链接仍可由用户主动点击打开联网网页。

这是当前页面的静态快照，不是整个网站镜像：折叠内容需先展开，虚拟列表不保证全量还原，封闭组件和受保护资源可能无法捕获；视频、音频保存静态预览，不保存流媒体。正文剪藏使用本地 Readability 提取文章，不支持正文编辑。

## 高亮、批注与阅读笔记

打开普通网页的拾页入口后，选中文字会出现划词工具条，可高亮、写批注或将选区收藏到客户端。高亮支持黄/绿/蓝/粉/紫五色、跨行内节点与跨段落、修改颜色、定位、隐藏与删除。点击高亮可直接打开对应批注；也可从保存面板的“标注与笔记”进入。未定位的标注保留摘录并明确标记，不盲目标到相似段落。笔记为纯文本，正文快照不可编辑。

笔记面板同时提供整页笔记、收藏夹、逗号分隔标签、星标和已读状态。编辑后点击“保存笔记与整理”或“保存批注”。未保存草稿会阻止收藏/导出；切换网页或记录时会提示。正常页面离开前有浏览器未保存提示，但不承诺浏览器崩溃时恢复未保存草稿。

笔记首先写入本浏览器的本地存储，不需要运行客户端。获得长期站点授权的网站在保存高亮后会注册静默恢复脚本：只恢复当前网址已有标注，不显示保存面板、不记录浏览历史、不唤醒客户端。尚未获得长期授权时，从工具栏重新打开拾页即可恢复。插件设置可关闭划词工具条或自动恢复，并选择默认颜色；常驻“保存入口”仍由独立的逐站开关控制。

点击“同步客户端”手动双向合并当前网页的记录；不会启动 Cubox 或连接它的账号/云服务。收藏整页时也带入标注与笔记。不同快照共享同一来源网址的阅读记录；普通锚点不分开存储，`#/`和`#!`路由分开。合并使用逐条版本和删除记录，旧备份或旧快照不会把已删除的高亮复活。同步并非后台实时云同步，客户端修改后请在浏览器再次点击同步。

工具栏弹窗“我的标注与笔记”进入本地笔记库，可按标题/网址/标签/摘录/笔记检索、筛选未读/星标/有笔记，编辑与同步，导出单页 Markdown 或备份/合并导入全部笔记 JSON。下载默认使用本地时间戳。原网页与输入框中的脚本不会从笔记内容执行。

右键菜单提供打开收藏面板、划词高亮/批注、选区摘录、链接和图片收藏；默认 `Alt+Shift+H` 高亮选区，`Ctrl+Shift+Y`（macOS为`⌘⇧Y`）打开插件，可在浏览器快捷键页修改。上述通用网页菜单不参与 ChatGPT 的原消息导出流程。

选区保存为独立纯文本摘录；链接收藏会注明尚未离线保存目标正文。图片在站点资源授权允许时读取并转为静态PNG，不携带登录凭据/referrer，不跟随重定向，源文件限16MiB、图像限4000万像素；受保护图片读取失败会明确提示。动图仅保存静态帧。

离线HTML和客户端PDF保留高亮并附加已保存的阅读笔记；原始快照文件仍保持不变。JSON包含独立的reading记录，Markdown/TXT同样带笔记。浏览器每页最多500条标注、512KiB记录；笔记总量受浏览器local存储配额限制，配额不足会报错，不显示成功。当前只支持主文档文字，不支持PDF内页、跨源iframe、封闭Shadow组件或图片内的文字标注；网页大改版、重复内容歧义可能导致定位失败。

## ChatGPT 页面内交互

- 输入框附近的 SELECT / EXPORT 分体按钮，带选择范围和导出格式菜单；无输入框时使用浮动入口。
- “选择消息”侧栏默认宽 320px，可左右停靠、拖拽内侧边缘调宽，也可聚焦边缘后用方向键调宽。
- 全部、提问、回答、清空、反选；Shift 点击连续选择或取消，底部全选框显示部分选中状态。
- 点击消息展开或折叠，悬停显示完整文本；支持全部展开、倒序显示和滚动到底部。消息角色以图标区分，AI 使用提供的 SVG，用户使用人像图标；选择栏不混入网页的“ChatGPT说:”等辅助角色标题。
- 侧栏切换格式不会立即导出；页面 EXPORT 菜单选择格式会直接执行导出流程。
- 非 PDF 支持下载和复制剪贴板；可设置自动关闭侧栏、静默导出、询问保存位置。
- 默认文件名包含本地时间戳，如 `标题_20261105-194530.pdf`；所有导出格式均适用，PDF 弹窗内手动编辑的文件名会原样保留。
- 只选择一条 AI 回答时，用该回答中级别最高的标题预填文件名（H1 优先于 H2，同级取第一个）；无标题、仅选用户消息或选择多条消息时沿用会话标题。忽略隐藏标签与代码块中的伪标题，支持网页语义标题及 API Markdown 标题；此规则只影响文件名，不更改文档内容标题。
- PDF 设置保留在页面内弹窗，支持取消、Esc、点击遮罩关闭；生成完成后自动下载并显示完成提示。
- “目录”默认开启，控制 PDF 阅读器侧栏目录书签（`outline`）；“目录页”默认关闭，控制正文前的可点击目录页面（`toc`）。两项独立，Chromium 和 Pandoc 均支持，用户之前保存的目录页偏好继续保留。
- 设置与服务连接单独位于扩展设置页，不再承担消息选择和导出工作台的功能。

## 服务协议与数据

兼容现有 `/health`、`/api/usage`、`/api/pdf/v1`、任务查询与下载接口，不需要修改服务端。Bearer 令牌只发给配置的服务，拒绝重定向。原有 PDF 服务请求仍仅允许扩展页面和 ChatGPT 上的本扩展内容脚本调用；通用网站使用单独校验的快照消息通道。

偏好与 PDF 任务 ID 保存在扩展本地；备份不包含服务访问令牌。独立扩展不读取原插件的私有配置。

## 已知边界

- ChatGPT 会话内部接口可能改变，失效时回退至已加载网页消息并明确标记来源；不保证回退时获取完整长对话。
- Chromium 在导出时重新冻结网页样式、公式、SVG、图片与可读取字体，并滚动收集虚拟列表消息。仍无法取得网页节点时，会先确认是否补全，再交给现有服务端的 Markdown/KaTeX 渲染器重新排版；不会直接打印 Markdown 源码。服务未声明 `supportsMarkdownFallback` 时会停止补全导出。
- 网页图片、背景与可读取字体会内嵌；OpenAI 静态资源可由扩展后台补取，后台请求不携带登录凭据或服务令牌。仍无法读取的资源会记入警告，复杂多模态附件和动态组件不保证完整恢复。
- 模型和消息时间等额外元信息使用 Pandoc；网页模式跟随捕获内容。
- 本次按原插件的核心交互流程重写，未声称商业版本全部设置、提取器和所有页面形态完全等价。

## 1.9.3 界面与采集授权

插件工具栏、网页收藏和笔记界面与拾页客户端统一为蓝白风格。工具栏可直接唤起并检查客户端连接。首次保存网页时，浏览器会请求 HTTP 和 HTTPS 网站访问权限及网页快照权限，批准后跨站资源无需逐个来源授权；授权不会自动采集浏览记录。权限可在浏览器扩展管理页调整。受浏览器限制的页面无法采集，无法取得的资源仍会提示。

## 1.9.4 批注显示与设置

带批注的文字以蓝灰色下划线显示，纯高亮继续使用背景颜色。插件设置页采用与客户端一致的侧栏分类布局。

## 1.9.5 网站保存入口

新网站的“在此网站自动显示保存入口”默认勾选；首次保存时授权并注册该网站，后续打开显示右下角“存到拾页”按钮，点击后展开面板。取消勾选后会记住该网站的选择。

## 1.9.6 彩色批注下划线

批注下划线加粗，并跟随批注卡片中选择的五种颜色；纯高亮仍使用原有背景色。

## 1.9.9 贴边悬浮入口

在已开启自动入口的网站，入口以半隐藏按钮吸附在窗口左右边缘。拖动调整位置并跨页面记住；点击展开收藏面板。面板可隐藏当前网站入口，设置 → 网页收藏可全局关闭或恢复隐藏的网站。现有采集仍需网站授权。

## 1.9.10 全站入口

普通 HTTP(S) 网页加载后自动显示贴边入口，无需先点击保存。更新后浏览器可能要求确认新增的全站访问及采集权限。自动入口不会自动保存网页或唤起客户端；ChatGPT 保留专用交互。全局关闭及单站隐藏继续生效。

## 1.9.12 ChatGPT 贴边入口

ChatGPT 与普通网页使用相同尺寸的贴边按钮，共享左右位置与高度。点击打开原有消息选择器，消息目录、选择和导出方式不变。

## 1.9.13 ChatGPT 界面统一

消息选择器、选中态、菜单及 PDF 弹窗与拾页蓝白 / 深色风格统一；消息目录勾选与导出流程不变。

## 1.9.14 标注与笔记界面

网页笔记面板、划词工具条及独立笔记库统一蓝白风格，跟随系统支持深色主题。

## 必应翻译

在网页中选中文字，点击划词工具条的“翻译”；可译成中文或英语，并将译文追加为该选区的批注。已有批注不会被覆盖。插件弹窗的“必应翻译”打开独立翻译页，支持更多目标语言和复制译文。单次限制1000字符，不自动整页翻译，也不改写保存的网页原貌。

无需密钥或客户端。仅主动点击翻译时，选中或输入的文字会发送给必应；请求不附带Cookie或来源信息。最近80条译文缓存在扩展本机，30天后失效，可在翻译页清除。保存为批注的译文按现有笔记逻辑保留和同步，不随缓存清除。

使用必应网页接口，可能受到限流、验证和接口变更影响，失败时会保留原文并提示原因，不绕过验证。协议参考开源项目 [GTranslate / BingTranslator](https://github.com/d4n3436/GTranslate/blob/master/src/GTranslate/Translators/BingTranslator.cs)，独立实现，未加载远程脚本。

验证：`node exporter-extension/verify-translation.mjs`（隔离浏览器，必应响应模拟）；加 `BING_LIVE=1` 可额外检查真实接口。

本次验证：安装式浏览器模拟测试及现有标注、ChatGPT导出回归通过；真实必应网页可以读取，但翻译请求在本机返回异常（未获得有效译文），因此尚未确认当前网络下的真实翻译可用性。
