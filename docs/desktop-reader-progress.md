# 桌面客户端第一阶段进展

2026-11-05：已新增 `desktop-client/`，暂名“拾页”，版本 0.1.0；扩展 1.2.0 增加“存到拾页”。原商业副本 `local-extension/` 没有修改。

## 本阶段结论

- Tauri macOS arm64 应用及 DMG 已实际构建。安装体积明显小于把外部浏览器、Python 与 TeX 整套打包的方案；最终尺寸以交付包为准。
- Native Messaging 与私有 Unix Socket 的启动/接收路径已实现，首次配对在图形界面完成。实际浏览器冷启动尚未验收。
- SQLite 内容与管理状态、归档 JSON/HTML、离线阅读、目录与基本整理已实现。
- 独立 WKWebView 的 AppKit 打印探针产生空白页，因此没有继续使用此打印路径。
- 当前改用 WKWebView `createPDF` 分段矢量输出和 CoreGraphics 合成 A4。不能仅把整张长 PDF 裁成多页：测试发现这会把不可见正文带入每页文字提取结果；分区域调用 WebView 导出避免了该问题。
- 安全分页位置在阅读引擎中的临时文档计算，保护图表和文本行，输出仍是矢量文字。

## 已执行的检查

- Rust 内容库检查：持久保存、内容去重、中文查询、标签与阅读状态、完整快照恢复、非法 ID、分块错序/校验/重复提交。
- 扩展 Core 与 Background 联合检查：所选消息范围、单回答标题、分块在浏览器内部消息之前发生、Unicode、哈希与完成确认。Native API 使用模拟实现。

- Chromium UI 夹具：实际阅读界面、原貌样式与图表比例、脚本/外部资源阻断、目录、中文搜索、星标、收藏夹/标签/备注、已读、回收站恢复。原生命令接口模拟。
- 独立 WKWebView/CoreGraphics：120 行代码跨三页完整保留；彩色长图在第二页完整输出；页面有可提取文字，没有整页空白，也没有跨页重复末尾代码。
- 已有扩展规则与 UI 回归通过，旧服务导出路径保留。

## 0.3.0 / 扩展 1.4.0：菜单栏轻量服务

新增 Rust 菜单栏入口、独立后台任务窗口、延迟加载的阅读窗口和持久客户端设置。Native Host 用 `open -g --args --background` 请求后台启动。默认轻量模式隐藏 Dock 图标，关闭阅读窗口后继续提供服务；可从菜单栏打开内容库、进入轻量模式或完全退出。后台渲染只在任务到达时加载，队列为空时关闭 WebView，避免长期隐藏 WebView 的节流影响。

网页导出默认由客户端生成，Native Messaging 每块最多384 KiB回传 PDF，再由扩展后台提交浏览器下载。保留客户端选择保存位置模式，两个设置相互独立。下载只接受已完成的浏览器交付任务，按任务 UUID 读取固定临时路径，不接受任意文件路径；总大小上限256 MiB。旧插件未声明浏览器下载能力时继续使用客户端保存。旧数据库的任务默认仍走客户端保存，新任务在入队时冻结交付方式。

验证：Rust 持久设置、分块字节一致性、错误偏移、旧客户端交付；真实 Chromium 下设置界面和两种网页流程；后台任务成功/取消/失败；扩展后台回传合并与浏览器下载 API（模拟 Native/下载 API）。另启动隔离数据目录的真实打包 Tauri 后台进程，连续提交两次任务，均生成真实 PDF，阅读窗口从未创建，渲染窗口均在完成后释放。没有操作或退出用户正在使用的客户端。真实安装环境里的首次配对、系统级冷启动唤起、菜单栏点击和原生保存窗口仍需人工验收。

实现参考：[Tauri 系统托盘](https://v2.tauri.app/learn/system-tray/)、[后台节流的平台范围](https://v2.tauri.app/reference/config/#backgroundthrottling)。后台任务窗口按需销毁，不依赖长期隐藏页面保持计时器活跃。

## 0.6.0 / 插件1.5.0：多浏览器连接监测与前台应用策略

设置页新增按扩展ID组织的配对卡片，自定义名称、追加配对、重新配对、移除确认。注册配置保留所有ID，移除只撤销指定ID；注册清单、启动脚本与授权列表采用临时文件替换，避免并行导出读取到部分写入。诊断分别显示浏览器注册是否存在、JSON/启动器路径是否有效及ID是否登记。

首次显式客户端操作成功后，插件建立独立connectNative持续通道，Native Host从实际调用参数绑定来源ID并生成会话UUID，覆盖消息自行声明的身份。同ID可有多个浏览器/配置会话。每3秒心跳，正常断开单独标记，20秒超时判断异常掉线；主动检测用随机挑战/响应，15秒超时，显示插件版本与往返耗时。最近通信时间独立保存且限制写入频率；实时会话不持久化为在线。原有导出消息不迁移到监测通道。

检测通道不唤醒客户端：Host先读取首条请求，再决定是否允许启动应用；connection_open在应用未运行时直接返回等待状态。断开最多尝试重连两次，后续显式操作恢复。浏览器启动/插件重新加载不主动连接。持续会话保留Native Host与扩展Worker，无额外阅读/PDF WebView。

修正轻量模式始终设置Accessory的行为：阅读或设置窗口打开时切换Regular，关闭最后一个应用窗口时回到Accessory；隐藏导出worker不影响Dock策略。菜单栏“进入轻量模式”同时收起阅读和设置窗口。非轻量模式保持普通应用。
