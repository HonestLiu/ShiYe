# 拾页实施路线图

以最初的[规划](desktop-reader-plan.md)为依据，按实际交付更新。客户端不集成 Pandoc；商业副本 `local-extension/` 保持不动。文章正文提取与云同步继续后置。正文可编辑功能已按用户要求取消。

## 已交付

- [x] 五色高亮、段落批注与整页笔记，浏览器/客户端笔记库、手动双向同步、笔记备份/导出，选区/链接/图片收藏。

- [x] 通用网页静态快照、独立页内面板、离线HTML下载与客户端收藏，插件更名为拾页·稍后读助手。

- [x] 多扩展ID/浏览器会话监测、主动检测与配对管理，轻量模式前台Dock行为修正。
- [x] 独立设置窗口、⌘,与菜单栏入口，启动方式、后台下载、阅读/PDF默认值、配对和备份集中管理。
- [x] macOS Apple Silicon 安装包，Tauri + WKWebView，无外部 Chrome 运行依赖。
- [x] 扩展配对、分块接收、离线内容库、独立阅读目录和基本整理。
- [x] 原貌 PDF 及高级设置，PDF/HTML/Markdown/TXT/JSON、备份与恢复。
- [x] 菜单栏轻量服务、后台渲染、浏览器下载/客户端保存两种交付方式。
- [x] 仅导出 PDF 可不加入内容库；用户图片提问识别及完整比例图片排版。
- [x] 批量整理：多选、筛选范围全选、已读/星标/收藏夹/追加标签/回收站。
- [x] 批量导出：五种格式、持久队列、时间戳与重名保护、进度、取消、部分失败明细。

“已交付”表示代码、构建和对应自动检查已完成，不代表所有系统与真实浏览器流程均验收通过。验证证据和边界见[进展记录](desktop-reader-progress.md)。
