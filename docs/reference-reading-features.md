## 数据与安全

浏览器按规范化URL保存reading记录，客户端在SQLite `reading_pages`表持久化；普通锚点共享记录，hash路由区分。同一来源的多个收藏共享阅读记录。每条标注保留TextQuote、前后文、位置、颜色、批注与版本；显示用摘录保留段落换行，定位仍使用稳定的文本索引。通过TreeWalker/Range定位，再分割文本节点插入语义mark，保留父元素与监听器，不重写文章innerHTML。绘制批量进入requestAnimationFrame，DOM变化才安排重定位，绘制自身的变更不会触发循环。

删除保留不含原文的ID/版本墓碑，合并不会复活旧副本；新旧快照也不覆盖期间更新的笔记。未保存草稿保持在当前界面，发生版本冲突会拒绝覆盖并提示保留/复制。未实现崩溃后的草稿恢复。笔记500条/页、记录512KiB/页，浏览器总量受local存储配额约束；写入失败不会当作成功。

内容脚本消息绑定本扩展、顶层标签页和当前URL；只有本扩展笔记库可列出/导入全部记录。快照、批注和标题中的用户内容分别清理或使用textContent/value，不执行笔记中的HTML。独立阅读文档继续禁用脚本、没有应用命令权限。Native Host仍要求扩展ID配对，独立设置/worker窗口不能调用阅读笔记命令。

新图片读取遵循既有资源规则：HTTP(S)、不带账号密码URL、omit凭据/no-referrer、拒绝重定向、超时/大小/像素限制、阻止跨源私网读取，再转PNG剥离动态内容。失败明确报告，不静默保存在线占位链接。来源链接可由用户主动打开。

快捷键与右键菜单使用用户触发的activeTab访问，不增加全站强制host权限；长期恢复只在已有授权下注册。依据：[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[按需权限](https://developer.chrome.com/docs/extensions/reference/api/permissions)。

## 0.9.0 / 扩展1.8.0：原貌与正文分开

原貌模式在浏览器当前布局上冻结计算样式、图片/SVG尺寸、伪元素与开放Shadow组件的遮罩；保留样式表media条件，按钮保留静态图标。客户端对普通网页停止舒适模式的全局列宽、背景和媒体尺寸改写，默认按来源视口自适应缩放。捕获临时属性按逆序恢复，不改变来源节点身份。

正文模式在离线HTML上运行本地Readability，去除导航/侧栏与原站排版，保留正文媒体/代码/表格；识别不足明确失败。引擎来源与Apache-2.0、思源适配代码MulanPSL-2.0许可放在扩展vendor目录。两种模式独立保存source/mode，不接入思源API，不改变ChatGPT导出UI。

验证包含18px高分辨率图标、SVG按钮、动态adoptedStyleSheets、print样式隔离、原页面恢复，以及真实MDN和阮一峰博客的两种采集、离线断网打开和截图对照。维基百科导航超时，未算通过。测试不保证所有登录站点/虚拟列表/封闭组件完整还原。
