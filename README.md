# 拾页 · 稍后读

拾页是一款以本地内容库为核心的稍后读软件：在浏览器里保存值得再读的网页、ChatGPT 对话和摘录，在 macOS 客户端中离线阅读、整理、标注并导出。浏览器扩展负责采集和网页交互，桌面客户端负责管理本地收藏与阅读；内容保存在自己的设备上，不依赖拾页云账户。

| 组件 | 当前版本 | 用途 |
| --- | --- | --- |
| [浏览器扩展](exporter-extension/README.md) | 1.10.3 | 网页快照、正文剪藏、划词标注与笔记、ChatGPT 对话导入和 PDF 导出 |
| [macOS 客户端](desktop-client/README.md) | 0.16.9 预览版 | 本地内容库、离线阅读、搜索整理、阅读标注、备份与导出 |
| [旧版 PDF 服务](local-pdf-server/README.md) | 可选 | 自托管的 ChatGPT PDF 导出与管理后台，属于兼容保留的独立工具 |

## 开始使用

当前桌面安装包面向 **macOS 13+、Apple Silicon（arm64）**。尚无 Windows/Linux 客户端发行包；预览版使用本地 ad-hoc 签名，未经过 Apple 开发者证书签名和公证。安装与配对步骤详见[客户端指南](desktop-client/README.md#安装与首次连接)。

1. 安装并打开“拾页”客户端。
2. 在 Chrome、Edge 等 Chromium 浏览器加载本仓库的 `exporter-extension/` 文件夹作为未打包扩展。
3. 打开客户端“设置 → 浏览器连接”，按客户端指南完成一次扩展 ID 配对。
4. 在普通网页打开拾页入口保存网页；在 ChatGPT 页面选择消息后点击“存到拾页”。

浏览器网页收藏直接通过扩展与本机客户端通信。阅读收藏、标注和笔记不需要启动 Python 服务或连接远程服务器。客户端也能独立管理已有内容；浏览器扩展中的标注和笔记可按需与客户端手动同步。

## 可以做什么

- **保存网页稍后读**：保存包含样式和资源的离线网页快照，同时生成去除导航干扰的正文剪藏；阅读时可在两种版本间切换。
- **收藏 ChatGPT 对话**：选择需要保留的消息并存入客户端，也可导出为 PDF、HTML、Markdown、TXT、JSON 等格式。
- **离线阅读与整理**：本地搜索、收藏夹、标签、备注、星标、已读状态、阅读进度、批量整理及可恢复回收站。
- **标注与笔记**：对网页文字高亮、添加批注和摘录，记录整页笔记；在浏览器与客户端之间手动合并记录。
- **编辑与导出**：编辑正文剪藏，导出单篇或批量 PDF、HTML、Markdown、TXT、归档 JSON，并备份或恢复本地内容库。

采集结果取决于来源网页：折叠内容需要先展开；虚拟列表、受保护资源和动态媒体可能无法完整保存。视频/音频作为静态预览保存，不复制流媒体。浏览器与客户端之间的标注同步是手动本地连接，不是实时云同步。更多功能边界、隐私与数据目录见[扩展指南](exporter-extension/README.md)和[客户端指南](desktop-client/README.md)。

## 开发

桌面客户端开发需要 Rust、Xcode 命令行工具和 Node/npm。构建、打包及检查命令见[客户端开发说明](desktop-client/README.md#构建与检查)。扩展的安装、功能和验证边界见[扩展说明](exporter-extension/README.md)。

## 旧版 PDF 服务

仓库早期以 ChatGPT 对话 PDF 导出服务为主。相关 Python 服务、Web 后台与 Docker 部署仍保留，可单独使用；它们不是稍后读客户端的运行依赖。若需要在服务器上自托管该服务，请看[部署指南](deploy/README.md)。
